# B动态批删脚本

### **TL;DR**: 

> 本脚本用于批量删除 Bilibili 用户动态，支持按类型筛选（转发、文字、图片、投稿），并提供删除进度显示及操作日志导出功能

- **安装浏览器扩展** [Tampermonkey](https://www.tampermonkey.net/)

- [安装脚本](https://greasyfork.org/zh-CN/scripts/521110-b%E7%AB%99%E5%8A%A8%E6%80%81%E6%89%B9%E9%87%8F%E5%88%A0%E9%99%A4%E5%B7%A5%E5%85%B7)

---

## **功能特性**

- **类型筛选**：可指定删除某类动态

- **日志导出**：生成 JSON 删除记录

- **进度显示**：实时展示删除数量

- **删除间隔自定义**：避免触发频控

### **更新日志**

- **v2.1.1**：「删除投稿动态」增加连带删除视频的强提醒确认弹窗（B站机制：投稿动态与视频稿件绑定，删除动态即删除视频）。
- **v2.1.0**：「视频动态」更名为「投稿动态」；修复扫描计数与实际不符的问题（扫描数实时刷新、按动态 id 去重、翻页游标防重、进度按匹配数计算）。
- **v2.0.0**：适配B站新版 Polymer 接口（旧版 `space_history` 已下线），删除接口迁移至 `operate/remove` 并保留旧接口回退；移除 axios 外部 CDN 依赖，改用原生 `fetch`；新增运行日志、停止按钮与风控重试。


### **使用步骤**

1. 打开 Bilibili 个人空间的 **动态**
  
2. 选择要删除的动态类型：

   - `删除转发动态`

   - `删除文字动态`

   - `删除图片动态`

   - `删除投稿动态`
  
3. 删除完成点击 `导出清除日志及内容` 保存记录

> ⚠️ **注意**：B站将「投稿动态」与「视频稿件」绑定（网页端手动点删除同样如此），删除投稿动态会**连带删除对应的视频投稿且无法恢复**。点击该按钮时脚本会弹出确认提示，请确认后再操作。
